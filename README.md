# ♟️ Chess Assistant

A powerful Chrome Extension that provides real-time chess analysis on Chess.com and Lichess using the Stockfish chess engine.

Whether you're studying games, reviewing positions, or improving your chess skills, Chess Assistant delivers fast and accurate analysis directly in your browser.

---

## 🚀 Features

- 🧠 Powered by Stockfish
- ♟️ Supports Chess.com and Lichess
- 📊 Real-time position evaluation
- 🎯 Best move suggestions
- ⚡ Fast and lightweight
- 🔧 Adjustable engine depth
- 🌐 Works directly in Chrome
- 🔄 Automatic board detection
- 🎨 Clean and user-friendly interface

---

## 📦 Installation

### 1. Download the Extension

Clone or download this repository:

```bash
git clone https://github.com/dearabesss/chess-assistant.git
```

### 2. Open Chrome Extensions

Navigate to:

```
chrome://extensions/
```

### 3. Enable Developer Mode

Turn on **Developer Mode** in the top-right corner.

### 4. Load the Extension

Click **Load unpacked** and select the extension folder.

### 5. Start Using

Open Chess.com or Lichess and start analyzing positions instantly.
